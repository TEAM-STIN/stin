# 기술 부채 트래커

**기술 부채는 고금리 대출과 같다.** 이자가 쌓여 한꺼번에 갚는 것보다 조금씩 꾸준히
갚는 편이 낫다. 몰아서 정리하는 방식은 2인 팀에서 확장되지 않는다.

## 쓰는 법

- 작업 중 발견한 부채를 **그 자리에서 고치지 못하면 여기 적는다.** 머릿속에 두지 않는다
- 관련 영역을 작업할 때 같이 처리한다
- 같은 항목이 반복해서 올라오면 [golden-rules.md](../golden-rules.md)나 린트 규칙으로 승격한다
- 처리한 항목은 지우지 말고 "해결"로 옮긴다 — 무엇이 왜 부채였는지가 기록으로 남는다
