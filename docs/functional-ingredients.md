# 기능성 성분 정리 (고민별)

피부 고민(`ConcernTag`)별 도움/회피 성분 정리 문서.

**구현 반영 상태**: 이 문서의 `[DB]` 항목은 아래에 반영됨.
- 스키마: `IngredientGroupConcern` 모델 + `ConcernEffect` enum — [schema.prisma](../apps/api/prisma/schema.prisma)
- 마이그레이션: `20260902000000_add_ingredient_group_concern`
- 시드: [seed.ts](../apps/api/prisma/seed.ts) — 그룹 11개 / 병용 규칙 8건 / 고민 매핑 40여 건
- 그룹 분할: `AHA/BHA류` → `AHA류` · `BHA류` · `PHA류` (LHA=캡릴로일살리실산은 BHA류 성분으로 편입)

## 정리 포맷

각 고민마다 아래 구조로 작성한다.

- **HELPS · 핵심 · [DB]** — 임상 근거 강함 (`evidenceLevel: ESTABLISHED`)
- **HELPS · 보조 · [DB]** — 근거 중간, 업계 통설 수준 (`evidenceLevel: COMMON_BELIEF`)
- **병행 권장 · [DB]** — 고민 자체를 겨냥하진 않지만 자극 완화·장벽 보충용 (HELPS로 저장하되 가중치 낮게)
- **AVOID** — 3가지 유형으로 분리하고, 각 항목이 어디서 관리되는지 명시한다
  - **회피 성분 · [DB]** → `IngredientGroupConcern` (effect=AVOID) 시드 데이터
  - **조합 주의 · [DB]** → `IngredientRule` (성분 그룹 간 병용 규칙) 시드 데이터
  - **사용 습관 · [정적 콘텐츠]** → 성분·제품과 연결 안 됨. **프론트에서 정적 콘텐츠로 관리** (DB 아님)

관리 위치 태그 표기:

| 태그 | 의미 |
|---|---|
| `[DB]` | Prisma 시드로 들어가는 데이터. 추천 로직이 참조 |
| `[정적 콘텐츠]` | 프론트엔드에서 하드코딩/상수로 관리. DB·추천 로직과 무관 |

### 자외선 차단제 취급

자외선 차단제는 이번 범위에서 **루틴 단계에 넣지 않고, 모든 고민 공통 안내 문구로만 노출**한다
("자외선 차단제를 함께 바르면 효과가 유지됩니다" 수준). 따라서:

- `IngredientGroup` / `IngredientGroupConcern`에 자외선 차단제 그룹을 만들지 **않는다** → 시드 변경 없음
- 각 고민의 자외선 차단제 언급은 `[정적 콘텐츠]`로 표기하고 프론트 안내 문구로 처리
- 스키마의 `StepCategory.SUNSCREEN`, `Routine.includeSunscreen`은 향후 확장 대비로 **남겨둔다**(현재 미사용)

> 모델링 메모: `IngredientRule`은 그룹 단위라, AHA와 BHA가 한 그룹이면 "AHA + BHA 동시 사용" 규칙을
> 표현할 수 없어 `AHA류` / `BHA류` / `PHA류`로 분리했다. `weight`는 HELPS 추천 점수 가중치(핵심 100 / 보조 60 / 병행 25),
> AVOID 행에서는 무시하고 제외·감점 필터로만 쓴다.

## 트러블 (TROUBLE)

여드름·면포·염증성 트러블. 원인 = 피지 과다 + 모공 각질 축적 + C. acnes + 염증.

### HELPS · 핵심 (ESTABLISHED)

| 성분 | 작용 | 비고 |
|---|---|---|
| 살리실산 (BHA) | 모공 속 각질·피지 용해, 면포 개선 | 0.5~2% |
| 아젤라익애씨드 | 항균 + 각질 + 항염 + 색소침착(PIH) 개선 | 10~20%, 트러블 자국까지 커버 |
| 레티노이드 (레티놀 / 아다팔렌) | 턴오버 촉진, 면포 형성 예방 | 아다팔렌은 여드름 OTC 표준. 초기 자극 주의 |
| 벤조일퍼옥사이드 | C. acnes 살균, 염증성 여드름 감소 | 의약외품/OTC. 표백·자극 주의 |
| 나이아신아마이드 | 피지 조절, 항염 | 2~5%, 저자극 |

### HELPS · 보조 (COMMON_BELIEF)

| 성분 | 작용 | 비고 |
|---|---|---|
| 만델릭애씨드 | 항균성 AHA, 면포·PIH 개선 | AHA 중 저자극 |
| 글라이콜릭 / 락틱애씨드 (AHA) | 표면 각질 제거로 모공 막힘 완화 | 보조 |
| 티트리 오일 | 항균·항염 | 5% gel이 BPO와 유사 효과(소규모 RCT). 향 자극 주의 |
| 아연 (Zinc PCA, Zinc gluconate) | 피지 억제, 항염 | 보조 |
| 황 (Sulfur) | 각질 용해, 항균 | 오래된 근거, 냄새 이슈 |

### 병행 권장 (장벽·진정)

판테놀, 센텔라(마데카소사이드·아시아티코사이드), 세라마이드, 알란토인, 비사보롤

### AVOID

**회피 성분 · [DB]**

| 구분 | 성분 |
|---|---|
| 코메도제닉 오일·에스터 | 코코넛오일, 코코아버터, 이소프로필미리스테이트, 이소프로필팔미테이트, 미리스틸미리스테이트 |
| 폐색성 유지 | 라놀린, 미네랄오일 과다 |
| 자극 유발 | 고농도 향료, 에센셜오일 다량, 변성알코올(SD/변성 알코올) 상위 배합 |

**조합 주의 · [DB]**

- 레티노이드 + AHA/BHA 동시간대 → 자극 누적
- 벤조일퍼옥사이드 + 레티놀 동시 도포 → 레티놀 산화·효능 저하 (아다팔렌은 안정, 예외)

**사용 습관 · [정적 콘텐츠]** — 프론트에서 관리, DB 아님

- 손·도구로 강한 압출
- 과도한 세안(하루 3회 이상), 뜨거운 물 세안
- 여러 활성 성분을 한 번에 도입

## 각질 (KERATIN)

묵은 각질, 피부결 거칠음, 각질 쌓임.

### HELPS · 핵심 (ESTABLISHED)

| 성분 | 작용 | 비고 |
|---|---|---|
| 글라이콜릭애씨드 (AHA) | 각질세포 결합 분해 → 표면 각질 탈락, 피부결·톤 개선 | 5~10%, 분자 작아 침투 좋음 |
| 락틱애씨드 (AHA) | 각질 제거 + 습윤(보습) 겸함 | 글라이콜릭보다 순함, 건성 각질에 적합 |
| 살리실산 (BHA) | 지용성, 모공 내부 각질 정리 | 지성·복합성 각질 |
| 우레아 | 고농도(10%+) 각질 용해 + 보습 | 저농도는 보습, 고농도는 각질용해제 |

### HELPS · 보조 (COMMON_BELIEF)

| 성분 | 작용 | 비고 |
|---|---|---|
| 만델릭애씨드 | 저자극 AHA | 민감·초보용 |
| PHA (글루코노락톤, 락토바이오닉애씨드) | 분자 커서 저자극 각질제거 | 민감성 각질 |
| 효소 (파파인, 브로멜라인) | 단백질 분해로 각질 연화 | 물리 자극 없음, 근거 제한적 |
| 글리세린 · 판테놀 | 각질층 수분 보충 → 매끄러움 | 직접 각질제거는 아님 |

### 병행 권장 (장벽)

세라마이드, 콜레스테롤, 지방산, 히알루론산, 판테놀

### AVOID

**회피 성분 · [DB]**

| 구분 | 성분 |
|---|---|
| 탈수 유발 | 고농도 변성알코올 상위 배합 |

**조합 주의 · [DB]**

- AHA + BHA + 스크럽 동시간대 → 장벽 손상, 오히려 각질 이상
- 레티노이드 + AHA/BHA 동시간대

**사용 습관 · [정적 콘텐츠]** — 프론트에서 관리, DB 아님

- 굵은 입자 물리 스크럽
- 잦은 클렌징 브러시 사용
- 주 3회 초과 고농도 필링

## 모공 (PORE)

모공이 도드라져 보임, 블랙헤드, 늘어진 모공. 모공 크기 자체는 되돌릴 수 없고 "덜 도드라지게" 관리.
원인 = 피지 과다 + 각질 축적 + 탄력 저하 + 광노화.

### HELPS · 핵심 (ESTABLISHED)

| 성분 | 작용 | 비고 |
|---|---|---|
| 살리실산 (BHA) | 모공 속 피지·각질 제거, 블랙헤드 개선 | 0.5~2% |
| 나이아신아마이드 | 피지 분비 감소, 모공 외관 개선 | 2~5%, 임상 근거 있음 |
| 레티노이드 (레티놀) | 턴오버·콜라겐 → 모공 벽 탄력, 각질 축적 감소 | 저녁 사용 |

### HELPS · 보조 (COMMON_BELIEF)

| 성분 | 작용 | 비고 |
|---|---|---|
| AHA (글라이콜릭 / 락틱) | 표면 각질로 인한 모공 막힘 완화 | 보조 |
| 아젤라익애씨드 | 각질 + 피지 + 항염 | |
| 점토 (카올린, 벤토나이트) | 일시적 피지 흡착 | 워시오프 한정 |
| 아연 (Zinc PCA) | 피지 조절 보조 | |

### 병행 권장 · [DB]

비타민C·비타민E (콜라겐·탄력 보조)

### 안내 문구 · [정적 콘텐츠]

자외선 차단제 — 광노화성 모공 확장 예방. 함께 바르면 관리 효과가 유지됨

### AVOID

**회피 성분 · [DB]**

| 구분 | 성분 |
|---|---|
| 코메도제닉 오일·에스터 | 코코넛오일, 이소프로필미리스테이트, 이소프로필팔미테이트, 코코아버터 |
| 폐색성 유지 | 무거운 미네랄오일·밤 과다 |
| 탈수 유발 | 고농도 알코올 (피지 반동 증가) |

**조합 주의 · [DB]**

- 레티노이드 + AHA/BHA 동시간대

**사용 습관 · [정적 콘텐츠]** — 프론트에서 관리, DB 아님

- 강한 압출, 블랙헤드 물리 제거
- 거친 스크럽
- 피지 과다 제거 후 보습 생략

## 홍조 (REDNESS)

지속적 붉음, 혈관 확장, 주사(rosacea) 경향.

### HELPS · 핵심 (ESTABLISHED)

| 성분 | 작용 | 비고 |
|---|---|---|
| 아젤라익애씨드 | 항염, 혈관 반응 완화 | 10~20%, 주사 임상 근거 강함 |
| 나이아신아마이드 | 염증 완화, 장벽 강화 | 2~5% |

### HELPS · 보조 (COMMON_BELIEF)

| 성분 | 작용 | 비고 |
|---|---|---|
| 감초 추출물 (글리시리진산, 글라브리딘) | 항염 | |
| 센텔라 (마데카소사이드, 아시아티코사이드) | 항염, 혈관 진정 | |
| 그린티 (EGCG) | 항산화·항염 | |
| 비사보롤 | 항염 | |
| 판테놀 | 진정·장벽 보충 | |

### 병행 권장 (장벽)

세라마이드, 콜레스테롤, 히알루론산

### AVOID

**회피 성분 · [DB]**

| 구분 | 성분 |
|---|---|
| 청량감·자극 | 멘톨, 캠퍼, 페퍼민트, 유칼립투스 |
| 향·오일 | 고농도 향료, 에센셜오일(특히 시트러스·페퍼민트) |
| 자극 유발 | 변성알코올 상위 배합, 고농도 비타민C(L-아스코빅애씨드, 낮은 pH) |

**조합 주의 · [DB]**

- 레티노이드 + AHA/BHA
- 물리 + 화학 각질제거 중복

**사용 습관 · [정적 콘텐츠]** — 프론트에서 관리, DB 아님

- 사우나·뜨거운 물·급격한 온도차
- 문지르는 클렌징, 강한 마찰
- 자외선 노출 (선크림 필수)
- 매운 음식·알코올·카페인 등 트리거

## 민감 (SENSITIVE)

자극 반응이 잘 일어남, 따가움·화끈거림, 장벽이 약함.

### HELPS · 핵심 (ESTABLISHED)

| 성분 | 작용 | 비고 |
|---|---|---|
| 세라마이드 (+ 콜레스테롤 + 지방산) | 장벽 지질 복구 | 대략 3:1:1 비율일 때 회복 효과 |
| 판테놀 | 보습 + 상처 치유 + 자극 완화 | |
| 나이아신아마이드 | 장벽 강화, 항염 | 2~4% 권장 (고농도 시 일부 자극) |

### HELPS · 보조 (COMMON_BELIEF)

| 성분 | 작용 | 비고 |
|---|---|---|
| 마데카소사이드 / 센텔라 | 항염, 진정 | |
| 베타글루칸 | 보습 + 진정 | |
| 콜로이달 오트밀 (아베나노사이드) | 항염 | 미국 FDA 피부보호제 인정 |
| 알란토인 | 진정, 각질 완화 | |
| 비사보롤 | 항염 | |

### 병행 권장 (저자극 보습)

히알루론산, 글리세린

### AVOID

**회피 성분 · [DB]**

| 구분 | 성분 |
|---|---|
| 착향·오일 | 향료(착향제), 에센셜오일 |
| 알코올 | 변성알코올 상위 배합 |
| 고농도 활성 | 고농도 AHA/BHA, 고농도 비타민C |
| 청량감 | 멘톨, 캠퍼, 유칼립투스 |
| 자외선 필터 | 옥시벤존 등 일부 화학필터 → 무기자차 권장 |

**조합 주의 · [DB]**

- 레티노이드 + AHA/BHA
- 여러 활성 성분 동시 사용

**사용 습관 · [정적 콘텐츠]** — 프론트에서 관리, DB 아님

- 새 제품 여러 개 동시 도입, 패치 테스트 생략
- 잦은 각질제거
- 뜨거운 물, 강한 마찰, 긴 클렌징

## 주름 (WRINKLE)

잔주름, 탄력 저하, 광노화.

### HELPS · 핵심 (ESTABLISHED)

| 성분 | 작용 | 비고 |
|---|---|---|
| 레티노이드 (레티놀, 레티날, 트레티노인) | 콜라겐 합성 촉진, 광노화 개선 | 근거 최상. 저녁 사용, 초기 자극 주의 |
| 비타민C (L-아스코빅애씨드) | 콜라겐 합성 보조, 항산화 | 10~20% |

### HELPS · 보조 (COMMON_BELIEF)
