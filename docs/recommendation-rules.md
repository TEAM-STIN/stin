# 추천 규칙 메모

고민별 도움/회피 성분 데이터는 [functional-ingredients.md](functional-ingredients.md) 참고.
이 문서는 거기서 다루지 않는 프론트 쪽 규칙만 모은다.

## 루틴 구성 모델

- 단계 = **토너 · 세럼(가벼운 / 고농축) · 크림**
- **선크림·클렌징 제품은 단계 수에서 제외.**
  선크림은 사용자가 온보딩에서 고르는 옵션이 아니라 모든 고민 공통 안내 문구로 노출한다
  (`functional-ingredients.md`의 "자외선 차단제 취급" 참고).
- 시간대: **오전 / 오후**

| 레벨 | 구성 |
| --- | --- |
| 2단계 | 토너 · 크림 |
| 3단계 | 토너 · 세럼 · 크림 |
| 4단계 | 토너 · 가벼운 세럼 · 고농축 세럼 · 크림 |

`@stin/types`의 `OnboardingInput`은 `skinType` · `concerns` · `routineLevel`만 담는다
(선크림·클렌징·아이크림은 사용자 입력 값이 아님).

## 제품 교체 안내 문구 예시

제품 교체 바텀시트/루틴 결과 화면(#13·#14)에서 쓸 안내 문구. 프론트 정적 콘텐츠.

| 상황 | 문구 |
| --- | --- |
| 성분이 안 맞을 경우 | 토너의 OO 성분과 병용을 추천하지 않아요 |
| 광과민성 주의해야 될 경우 | 이 제품은 자외선에 민감해서 썬크림을 바르는걸 추천해요 |
| 자극이 강한 제품일 경우 | 이 제품은 피부 자극이 강할 수 있어 매일 바르는걸 추천하지 않아요 |
